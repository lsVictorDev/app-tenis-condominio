# 🎾 App Tênis Condomínio

Aplicativo mobile desenvolvido em Flutter para gerenciamento de partidas, desafios, ranking de jogadores e reservas de quadras de tênis em condomínios.

## 📱 Sobre o projeto

O objetivo deste aplicativo é facilitar a organização de partidas de tênis entre moradores de condomínios, permitindo que jogadores possam acompanhar rankings, criar desafios e gerenciar reservas das quadras.

## 🚀 Tecnologias utilizadas

- Dart
- Material Design
- Git e GitHub

## ▶️ Como executar o projeto

Pré-requisitos:

- Flutter instalado
- Android Studio ou outro ambiente configurado
- Emulador Android ou dispositivo físico

Clone o projeto:

```bash
git clone https://github.com/lsVictorDev/app-tenis-condominio.git 
```
Entre na pasta:

```bash
cd app-tenis-condominio
```
Instale as dependências:

```bash
flutter pub get
```
Execute o aplicativo:

```bash
flutter run
```
